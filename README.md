# ContentForge

Modern headless CMS built with Next.js 14, TypeScript and Payload CMS.

The project demonstrates a scalable content management architecture with:
- multilingual content
- SEO optimization
- API-driven content delivery
- role-based access control
- modern React data fetching patterns

## Tech stack

- Next.js 14 (App Router)
- React
- TypeScript
- Payload CMS
- PostgreSQL
- TanStack Query
- Tailwind CSS

## Features

- Content management panel
- Dynamic pages
- Media management
- Localization support
- SEO metadata management
- REST/GraphQL API integration
